# FinanceApp - Manajemen Keuangan Mahasiswa

Aplikasi manajemen keuangan pribadi berbasis web untuk mahasiswa.

## Fitur
- Dashboard dengan statistik dan grafik
- Manajemen transaksi (pemasukan, pengeluaran, transfer)
- Multi-akun (bank, tunai, e-wallet, kartu kredit)
- Anggaran bulanan per kategori
- Target keuangan dengan progress tracking
- Laporan dan grafik interaktif
- Export/Import data JSON
- Dark mode & responsive design

## Cara Menjalankan
Buka file `index.html` di browser (Chrome/Firefox/Edge).

## Teknologi
- HTML5 + CSS3 + Vanilla JavaScript
- Chart.js untuk grafik
- localStorage untuk penyimpanan data
- Font Awesome untuk ikon
